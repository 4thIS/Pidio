# Pidio 구현 계획 (Implementation Plan)

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 학교 TV에 연결된 Raspberry Pi 5에서, 교직원이 교내 웹으로 동영상·사진·음악을 선택/반복/셔플/예약 재생하고 원격 업로드하는 미디어 플레이어를 완성한다.

**Architecture:** FastAPI(백엔드) + SQLite + mpv 2인스턴스(화면·음악, IPC 소켓 제어) + Vue 3 SPA(정적 빌드). 백엔드 도메인 로직은 하드웨어 없이 단위테스트 가능하도록 mpv/USB를 추상화한다. 프론트는 PC에서 빌드 → FastAPI가 정적 서빙. 세 프로세스(web/mpv-video/mpv-music)는 systemd로 분리.

**Tech Stack:** Python 3.11+ (uv 관리), FastAPI, Uvicorn, SQLite(내장 sqlite3), pytest, mpv(JSON IPC), ffmpeg/ffprobe, Vue 3, Vite, vuedraggable(SortableJS), Node 20+.

**설계 근거 문서:** `docs/01_설계.MD` (이 계획은 그 스펙을 구현한다).

---

## Global Constraints

- **파이썬/의존성:** 3.11 이상, **uv로 관리**(pyproject.toml + uv.lock 커밋; 개발 시작 전 `uv sync` 필수). 백엔드 의존성 최소화(FastAPI, uvicorn, pytest, httpx(test), python-multipart(업로드)). ORM 미사용 — 표준 `sqlite3`로 얇은 데이터 계층 작성.
- **Node:** 20 LTS 이상. 프론트는 `frontend/`에서 Vite 빌드 → `backend/app/static/`로 출력.
- **하드웨어 타깃:** Raspberry Pi 5, **Raspberry Pi OS Lite (Bookworm, 64-bit)**. mpv는 KMS/DRM 출력(`--vo=gpu --gpu-context=drm` 또는 기본 drm), 데스크톱 불필요. 재생 사용자는 `video`·`render` 그룹.
- **시간대:** `Asia/Seoul` 고정 — 예약 재생이 로컬 시간 기준(필수).
- **네트워크:** 교내 LAN 전용. 서버 바인드 `0.0.0.0:8000`. 원격 터널 없음.
- **개발 OS:** CW·DJ 모두 Windows. 순수 로직은 Windows에서 테스트, 실제 mpv/USB 통합은 RPi5(SSH).
- **미디어 식별자:** `content_id = f"{size}-{sha1(앞1MB)}-{sha1(뒤1MB)}"` (파일 <2MB면 전체 1회 해시). 경로 아님.
- **개발 규율:** TDD(실패 테스트 → 최소 구현 → 통과 → 커밋). DRY, YAGNI. 커밋은 작게 자주. 커밋 메시지 규칙: `feat:`, `fix:`, `test:`, `chore:`, `docs:` 접두어 + 한글 설명 가능.
- **소유자 표기:** 각 태스크 제목에 `[CW]` / `[DJ]` / `[공동]` 표기. CW=백엔드 도메인·플레이어 제어, DJ=웹/API·프론트.
- **경로 규칙:** 리포 루트 기준 상대경로. 백엔드는 `backend/`, 프론트는 `frontend/`.

**Interfaces (Produces):** 아래 타입·시그니처는 CW(구현)와 DJ(웹에서 호출) 모두의 계약.

```python
# backend/app/domain/contracts.py
from __future__ import annotations
from dataclasses import dataclass, field
from typing import Protocol, Literal, Optional

RepeatMode = Literal["off", "all", "one"]
PlayMode = Literal["auto", "manual"]
MediaType = Literal["video", "photo", "music"]

@dataclass
class Block:
    """재생 단위. kind='video'는 동영상 1개, kind='slideshow'는 사진들+선택 음악."""
    kind: Literal["video", "slideshow"]
    video_id: Optional[str] = None                 # kind='video'
    music_id: Optional[str] = None                 # kind='slideshow' 배경음악(None=무음)
    photos: list[tuple[str, float]] = field(default_factory=list)  # (photo_id, 표시초) 목록

@dataclass
class PlayerState:
    status: Literal["playing", "paused", "standby"]
    mode: PlayMode
    repeat: RepeatMode
    shuffle: bool
    queue_len: int
    current_index: int
    current_title: Optional[str]
    source_label: Optional[str]     # 예 "졸업식 플리 (3/12)" 또는 "전체 선택"
    position_sec: float
    duration_sec: float

class MpvClient(Protocol):
    """단일 mpv 인스턴스 제어. 화면용/음악용 각각 주입."""
    def loadfile(self, path: str, extra: dict | None = None) -> None: ...
    def set_property(self, name: str, value) -> None: ...
    def command(self, *args) -> None: ...
    def stop(self) -> None: ...
    # end-file 이벤트 콜백 등록(자연 종료 통지)
    def on_end_file(self, callback) -> None: ...

class PlayerController(Protocol):
    """웹 계층이 호출하는 재생 제어 표면."""
    def get_state(self) -> PlayerState: ...
    def play_blocks(self, blocks: list[Block], source_label: str,
                    repeat: RepeatMode = "off", shuffle: bool = False,
                    manual: bool = True) -> None: ...
    def next(self) -> None: ...
    def prev(self) -> None: ...
    def jump_to(self, index: int) -> None: ...
    def pause(self) -> None: ...
    def resume(self) -> None: ...
    def stop_to_standby(self) -> None: ...
    def set_repeat(self, mode: RepeatMode) -> None: ...
    def set_shuffle(self, on: bool) -> None: ...
    def enqueue(self, blocks: list[Block]) -> None: ...
    def remove(self, index: int) -> None: ...
    def reorder(self, from_index: int, to_index: int) -> None: ...
    def resume_auto(self) -> None: ...       # 수동→자동 복귀
```

```markdown
# HTTP API 계약 (v1)
인증: 모든 /api 는 세션 쿠키 필요(로그인 제외). 401 시 프론트가 로그인 화면.

## 인증
POST /api/login {password}            -> 200 set-cookie / 401
POST /api/logout                      -> 200

## 미디어
GET  /api/media?type=video|photo|music|all   -> [{content_id,media_type,title,duration,thumb_url,available}]
PATCH /api/media/{content_id} {custom_title} -> 200
POST /api/upload (multipart, chunked; 아래 업로드 프로토콜)   -> {content_id}
GET  /stream/{content_id}             -> Range 지원 원본 스트림(호버 미리보기/재생)
GET  /thumb/{content_id}              -> jpeg

## 플레이리스트
GET  /api/playlists                   -> [{id,name,item_count,total_sec,cover_thumb_urls[],repeat_mode,shuffle,schedule?}]
POST /api/playlists {name}            -> {id}
GET  /api/playlists/{id}              -> {id,name,repeat_mode,shuffle,blocks:[...], schedule?}
PUT  /api/playlists/{id}              -> 200 (blocks 전체 저장: video/slideshow 구조)
DELETE /api/playlists/{id}            -> 200
POST /api/playlists/{id}/play         -> 200 (수동 모드로 이 플리 재생)

## 예약
```

```python
# backend/app/domain/identity.py
import hashlib, os

_CHUNK = 1024 * 1024  # 1MB

def compute_content_id(path: str) -> str:
    size = os.path.getsize(path)
    with open(path, "rb") as f:
        if size <= 2 * _CHUNK:
            head = f.read()
            tail = b""
        else:
            head = f.read(_CHUNK)
            f.seek(-_CHUNK, os.SEEK_END)
            tail = f.read(_CHUNK)
    h1 = hashlib.sha1(head).hexdigest()[:16]
    h2 = hashlib.sha1(tail).hexdigest()[:16]
    return f"{size}-{h1}-{h2}"
```

```python
def _now(): return dt.datetime.now().isoformat(timespec="seconds")

def upsert_media(conn, content_id, media_type, original_name, rel_path, duration=None):
    row = conn.execute("SELECT content_id FROM media WHERE content_id=?", (content_id,)).fetchone()
    if row:
        conn.execute("""UPDATE media SET rel_path=?, available=1, last_seen=?,
                        duration=COALESCE(?, duration) WHERE content_id=?""",
                     (rel_path, _now(), duration, content_id))
    else:
        conn.execute("""INSERT INTO media(content_id,media_type,original_name,rel_path,
                        duration,default_photo_sec,available,first_seen,last_seen)
                        VALUES(?,?,?,?,?,?,1,?,?)""",
                     (content_id, media_type, original_name, rel_path, duration,
                      5.0 if media_type=="photo" else None, _now(), _now()))
    conn.commit()

def set_available(conn, content_ids):
    conn.execute("UPDATE media SET available=0")
    if content_ids:
        q = ",".join("?"*len(content_ids))
        conn.execute(f"UPDATE media SET available=1 WHERE content_id IN ({q})", tuple(content_ids))
    conn.commit()

def get_media(conn, content_id):
    r = conn.execute("SELECT * FROM media WHERE content_id=?", (content_id,)).fetchone()

        rows = conn.execute("SELECT * FROM media WHERE available=1 AND media_type=? ORDER BY original_name",(media_type,))
    else:
        rows = conn.execute("SELECT * FROM media WHERE available=1 ORDER BY media_type, original_name")
    return [dict(r) for r in rows]

    conn.execute("UPDATE media SET custom_title=? WHERE content_id=?", (title, content_id))
```

```python
def scan_library(conn, usb_root, id_fn=compute_content_id):
    seen, added = set(), []
    for folder,(mtype,exts) in _FOLDERS.items():
        base = os.path.join(usb_root, folder)
        if not os.path.isdir(base): continue
        for dirpath,_,files in os.walk(base):

                cid = id_fn(full)
                existed = mr.get_media(conn, cid) is not None
                mr.upsert_media(conn, cid, mtype, name, rel)
                seen.add(cid)
                if not existed: added.append(cid)
```

```python
# backend/app/domain/mpv_ipc.py
import json, socket, threading

def encode_command(args: list) -> str:
    return json.dumps({"command": args}) + "\n"

class MpvIpc:
    """Pi에서 유닉스 소켓으로 mpv 제어. on_end_file 콜백은 이벤트 리더 스레드에서 호출."""
    def __init__(self, sock_path: str):
        self.sock_path = sock_path
        self._end_cb = None
        self._sock = None

    def connect(self):
        s = socket.socket(socket.AF_UNIX, socket.SOCK_STREAM)
        s.connect(self.sock_path)
        self._sock = s
        threading.Thread(target=self._reader, daemon=True).start()

    def _send(self, args):
        self._sock.sendall(encode_command(args).encode())

    def _reader(self):
        buf = b""
        for chunk in iter(lambda: self._sock.recv(4096), b""):
            buf += chunk
            while b"\n" in buf:
                line, buf = buf.split(b"\n", 1)
                try: msg = json.loads(line)
                except ValueError: continue
                if msg.get("event") == "end-file" and self._end_cb:
                    self._end_cb(msg.get("reason"))

    def loadfile(self, path, extra=None):
        self._send(["loadfile", path, "replace"])
        if extra:
            for k,v in extra.items(): self._send(["set_property", k, v])
    def set_property(self, name, value): self._send(["set_property", name, value])
    def command(self, *args): self._send(list(args))
    def stop(self): self._send(["stop"])
    def on_end_file(self, callback): self._end_cb = callback
```

> **주:** `AF_UNIX`는 Windows 파이썬 3.9+에서 미지원일 수 있어 이 클래스의 **소켓 부분은 Pi에서만 실행**된다. 단위테스트는 `encode_command`(순수함수)만 검증하고, 통합은 Phase 10에서 Pi로 확인. 도메인 로직은 `MpvClient` 프로토콜(목)로 테스트하므로 문제없음.

```python
# backend/app/domain/player.py
import random
from .contracts import Block, PlayerState

class Player:
    def __init__(self, video, music, standby_image, music_screen_image):
        self.v, self.m = video, music
        self.standby_image = standby_image
        self.music_screen_image = music_screen_image
        self.queue: list[Block] = []
        self.order: list[int] = []      # shuffle 반영된 재생 순서(원본 인덱스 목록)
        self.pos = -1                    # order 상의 위치
        self.repeat = "off"; self.shuffle = False; self.mode = "manual"
        self.status = "standby"; self.source_label = None
        self._photo_idx = 0
        self.v.on_end_file(lambda reason: self._on_end())

    # ---- 공개 API ----
    def play_blocks(self, blocks, source_label, repeat="off", shuffle=False, manual=True):
        self.queue = list(blocks); self.source_label = source_label
        self.repeat = repeat; self.shuffle = shuffle
        self.mode = "manual" if manual else "auto"
        self._rebuild_order()
        self.pos = 0 if self.order else -1
        self._load_current()

    def _rebuild_order(self):
        self.order = list(range(len(self.queue)))
        if self.shuffle: random.shuffle(self.order)

    def _current_block(self):
        if self.pos < 0 or self.pos >= len(self.order): return None
        return self.queue[self.order[self.pos]]

    def _load_current(self):
        b = self._current_block()
        if b is None:
            self.status = "standby"
            self.v.loadfile(self.standby_image, {"image-display-duration": "inf"})
            self.m.stop(); return
        self.status = "playing"; self._photo_idx = 0
        if b.kind == "video":
```

```python
# backend/app/domain/scheduler.py
import datetime as dt
_WD = ["mon","tue","wed","thu","fri","sat","sun"]

def _weekly_active(s, now):
    if _WD[now.weekday()] not in s["weekdays"].split(","): return False
    st = dt.time.fromisoformat(s["start_time"]); en = dt.time.fromisoformat(s["end_time"])
    return st <= now.time() < en

def _date_active(s, now):
    st = dt.datetime.fromisoformat(s["start_dt"]); en = dt.datetime.fromisoformat(s["end_dt"])
    return st <= now < en

def active_playlist_id(schedules, now, default_id):
    weekly = [s for s in schedules if s.get("enabled",1) and s["sched_type"]=="weekly" and _weekly_active(s,now)]
    if weekly: return weekly[0]["playlist_id"]
    dated = [s for s in schedules if s.get("enabled",1) and s["sched_type"]=="date_range" and _date_active(s,now)]
    if dated: return dated[0]["playlist_id"]
    return default_id

def _time_ranges_overlap(a_s,a_e,b_s,b_e):
    return a_s < b_e and b_s < a_e

def overlaps_same_type(existing, new):
    for e in existing:
        if e["sched_type"] != new["sched_type"]: continue
        if new["sched_type"]=="weekly":
            if set(e["weekdays"].split(",")) & set(new["weekdays"].split(",")):
                if _time_ranges_overlap(dt.time.fromisoformat(e["start_time"]),dt.time.fromisoformat(e["end_time"]),
                                        dt.time.fromisoformat(new["start_time"]),dt.time.fromisoformat(new["end_time"])):
                    return True
        else:
            if _time_ranges_overlap(dt.datetime.fromisoformat(e["start_dt"]),dt.datetime.fromisoformat(e["end_dt"]),
                                    dt.datetime.fromisoformat(new["start_dt"]),dt.datetime.fromisoformat(new["end_dt"])):
                return True
    return False
```
